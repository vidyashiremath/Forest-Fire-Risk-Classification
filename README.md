
# Forest Fire Risk Classification

## Domain
Environment

## ML Task
Classification

## Problem Statement
Classify environmental observations according to forest-fire occurrence using machine learning techniques.

## Project Objective
Develop an end-to-end machine learning solution using the Algerian Forest Fires Dataset. The project includes data investigation, preprocessing, exploratory data analysis, model development, evaluation, and a lightweight Streamlit application.

## Dataset
Algerian Forest Fires Dataset

## Machine Learning Models
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- ROC-AUC
